# Space launcher icon attribution

The default launcher icon for this custom Telegram Android build is the
**Space** icon from [exteraGram](https://github.com/exteraSquad/exteraGram).

Source repository: https://github.com/exteraSquad/exteraGram
Source commit: `6f78031aafd7f27e0dfaa31a207715569a6df1a2`
Source paths: `TMessagesProj/src/main/res/mipmap-*/ic_*_space.webp`,
`TMessagesProj/src/main/res/mipmap-anydpi-v26/ic_launcher_space.xml`,
and `TMessagesProj/src/main/res/drawable/ic_monochrome.xml`.

exteraGram publishes its code under GNU GPL version 2.
The source files are incorporated unmodified. The only application change
is making the Space icon the default launcher icon in the standalone
Android manifest; all existing Telegram icons remain available.
